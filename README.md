# Reel Studio 網頁工單

- 使用者把素材與口白放進 Google Drive 資料夾，在網頁填工單，按「送出工單」會開啟郵件 App（mailto），信寄到 `z0fgxcnx+reel@mail.grokbot.com`。
- 只有學校信箱 `shinwei0623@gapp.ylsh.ilc.edu.tw` 寄的信會觸發史傳奇的 routine 開工；其他寄件者會被忽略。
- 不需要任何設定、不存任何金鑰。郵件 App 打不開時，可用「複製工單內容」貼到 Grok Bot 聊天。
- 網頁本身不處理、不上傳任何影片。示範截圖只用無人物的產品畫面。
